Private Fantasy Basketball Analytics

Copenhagen Vikings Fantasy Terminal

Copenhagen Vikings Fantasy Terminal is a private, non-commercial analytics application used for a single Yahoo Fantasy Basketball league. It is designed to support auction draft tracking, roster analysis, player valuation and fantasy performance analysis.

Intended Yahoo Fantasy API Use

The application uses Yahoo Fantasy Sports API access in read-only mode to retrieve fantasy league data for personal analytical use.

  • League information
  • Teams and rosters
  • Players
  • Matchups
  • Draft results and auction prices
  • Related fantasy basketball data

Purpose

Retrieved data is used to provide live auction draft tracking, roster analysis, budget monitoring, player valuation and fantasy performance analytics for a small private fantasy league.

Privacy & Distribution

This project is not intended for public distribution, resale or monetization. Yahoo Fantasy data is not sold, sublicensed or redistributed. Access is limited to personal use within a small private fantasy league.

Project Status

Private local application. Non-commercial. Expected usage is limited to a small number of users within one fantasy basketball league.
